# 規格與說明牌

## 文字

- **分詞器**：GPT-4o `o200k_base`（npm `gpt-tokenizer` 2.9.0），詞彙表 199,998。
- **信**：5,945 字、17,229 bytes → 5,366 tokens，其中 814 個是位元組碎片。
- 切之前去掉檔案第一行的語言切換連結，其餘照原檔，包含 Markdown 符號。
- Claude 的分詞器沒有公開，一律標示「GPT-4o 分詞器」。

## 圖片（CLIP ViT-L/14-336，LLaVA 使用）

- 用 CLIP 平均色（122, 116, 104）補成正方形，再縮成 336×336。
- 切成 24×24 = 576 塊，每塊 14×14 px。
- 每塊攤平成 14·14·3 = 588 個數字，轉成 1024 維向量。
- 圖塊之間的注意力是雙向的。
- 草叢照片：576 塊裡有 240 塊是補邊。

## 示意的部分

注意力連線、點雲位置、向量長相、機率地形的形狀都是示意。
