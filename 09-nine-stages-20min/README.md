# 09 — 九個階段（20 分鐘）

跟著估計的朗讀速度（`data/timing.json`，由 `tools/make_timing.py` 產生）。錄好朗讀後，用真實時間戳取代估計值再重算。

## 指令（在 repo 根目錄執行）

```bash
python3 09-nine-stages-20min/render_nine_full.py stills 30,400,900
python3 09-nine-stages-20min/render_nine_full.py video
```

輸出寫到 `out/`。
