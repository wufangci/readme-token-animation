# 13 — 3D 20 分鐘

和 v12 是同一條規則，掃描拉長到整個階段；各階段起點依信的段落（`02_timeline/timing.json`）；鏡頭轉兩圈。軟體 WebGL 每格約 0.2–0.3 秒，36,000 格分兩半同時算，約 1.5 小時。

## 指令（在 repo 根目錄執行）

```bash
python3 04_active/13-3d-20min/render3d_full.py stills 40,470,850,1110
04_active/13-3d-20min/run_full.sh
```

輸出寫到 `out/`。
