# 02_timeline — 時間軸

`timing.json` 記錄每個 token 在朗讀中的時間點，20 分鐘版（09、13）和聲音互動版的時間都依據它。

- **目前是估計值**（`make_timing.py`）：依字數加停頓估算。逗號加 0.5、句號／問號／驚嘆號加 1.2、段落加 3，分布在 3 秒到 1173 秒之間。
- **各段開始於**：0.05、2.87、5.54、8.76、12.52、15.68、19.21 分鐘。

```bash
python3 02_timeline/make_timing.py     # 重新產生 timing.json
```

## 錄好朗讀之後

1. 錄音放在 `02_timeline/recording/`（大檔不進 git，可以只放標記檔）。
2. 標出每段開頭的時間，最好能細到每句。
3. 用真實時間取代估計值，重算 09、13。
